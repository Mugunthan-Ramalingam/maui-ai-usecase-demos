# maui-ai-usecase-demos
"This repository provides ready‑to‑use, AI‑powered .NET MAUI use‑case samples built with Syncfusion’s AI AssistView control. It includes fully integrated implementations, best‑practice patterns, and real‑world scenarios to help developers quickly adopt and extend AI-driven features in their MAUI applications.

## Samples

| Sample | Description |
|--------|-------------|
| [AI-Powered Writing Assistant](AI-Powered Writing Assistant/README.md) | AI-assisted writing with RichTextEditor + AI AssistView (paraphrase, tone, grammar, elaborate, shorten). |
| [Smart Article Generator](Smart Article Generator/README.md) | Generates source-backed Markdown articles with Azure OpenAI and renders them in MarkdownViewer. |
| [Smart Vehicle Care](Use Case Samples/Smart Vehicle Care/README.md) | AI-powered vehicle management dashboard with service tracking, fuel logging, maintenance scheduling, nearby places, and an AI assistant. |
